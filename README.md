# BBM Sehat

Monorepo untuk aplikasi BBM Sehat (Bank BBM), terdiri dari dua proyek:

- **[`BBM SEHAT/`](./BBM%20SEHAT/)** — aplikasi mobile (Flutter). APK rilis
  ada di [`BBM SEHAT/releases/`](./BBM%20SEHAT/releases/).
- **[`bbm-sehat-backend/`](./bbm-sehat-backend/)** — backend (Laravel) dan
  dashboard admin (React, di `resources/js/admin/`).
